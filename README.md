# Nexment Docs

The official documentation site for **The Nexment Project**.

This is where Nexment's documentation, guides, references, and other useful project information live.

## About

The Nexment Docs site is built to make information about Nexment projects easy to find, understand, and use.

It may include documentation for:

- Nexment projects
- Developer tools
- CLI commands
- Guides and tutorials
- Configuration and usage
- Project references

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Font Awesome
- Google Fonts / Self-hosted fonts

## Project Structure

The website is built with the Next.js App Router.

```text
.
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── public/
│   ├── fonts/
│   ├── icons/
│   └── other assets
├── package.json
└── README.md
```

## Development

Clone the repository and install the dependencies:

```bash
git clone https://github.com/theNexmentProject/nexment-docs.git
cd nexment-docs
npm install
```

Start the development server:

```bash
npm run dev
```

The website will be available at:

`http://localhost:3000`
